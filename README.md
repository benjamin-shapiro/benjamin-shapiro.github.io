# Benjamin Shapiro Portfolio

Live site: [https://benjamin-shapiro.github.io/](https://benjamin-shapiro.github.io/)

## Local Live Preview

1. Install dependencies:
```bash
bundle install
```
2. Start the Jekyll preview server:
```bash
./bin/preview
```
3. Open: `http://127.0.0.1:4000`

Optional: enable LiveReload (if supported on your machine):
```bash
JEKYLL_LIVERELOAD=1 ./bin/preview
```

## Commit And Push To `main`

```bash
git checkout main
git pull --ff-only origin main
git add .
git commit -m "Your change summary"
git push origin main
```
